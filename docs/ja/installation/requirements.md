# システム要件
## PHP

| 要件 | 詳細 |
|------|------|
| バージョン | **8.2以上**（8.3推奨） |
| SAPI | FPM または CLI |

### 必須拡張

| 拡張 | 用途 |
|------|------|
| Ctype | 文字タイプチェック |
| cURL | HTTPリクエスト |
| DOM | XML/HTML パース |
| Fileinfo | MIME タイプ検出 |
| JSON | JSON エンコード/デコード |
| Mbstring | マルチバイト文字列処理 |
| OpenSSL | 暗号化と SSL |
| PCRE | 正規表現 |
| PDO | データベース抽象化 |
| Tokenizer | PHP トークナイザー |
| XML | XML パース |

### オプション拡張

| 拡張 | 用途 |
|------|------|
| BCMath | 任意精度数学 |
| Redis (phpredis) | Redis キャッシュドライバー |
| GD または Imagick | 画像処理 |

## データベース

| エンジン | バージョン |
|---------|-----------|
| MariaDB | **10.6以上**（推奨） |
| MySQL | **8.0以上** |

デフォルトのテーブルプレフィックスは `dls_` です。UTF-8（`utf8mb4`）文字セットが必要です。

## Web サーバー

| サーバー | バージョン |
|---------|-----------|
| Nginx | 1.18以上（推奨） |
| Apache | 2.4以上（`mod_rewrite` 必須） |

## ランタイムツール

| ツール | バージョン | 用途 |
|-------|-----------|------|
| Composer | 2.x | PHP 依存関係管理 |
| Node.js | 18以上 | フロントエンドアセットのコンパイル |
| npm | 9以上 | Node パッケージ管理 |

## Docker 要件（開発環境）

Docker セットアップを使用する場合、必要なものは以下のみです：

| ツール | バージョン |
|-------|-----------|
| Docker | 20.10以上 |
| Docker Compose | v2以上 |

その他の要件（PHP、MariaDB、Nginx、Node.js）はすべて Docker イメージに含まれています。

## ディレクトリパーミッション

Web サーバーユーザーは以下のディレクトリに書き込み権限が必要です：

| ディレクトリ | 用途 |
|-------------|------|
| `storage/` | ログ、キャッシュ、セッション、アップロード |
| `bootstrap/cache/` | フレームワークキャッシュ |
| `.env` | 環境設定 |

推奨パーミッション：ディレクトリは `775`、ファイルは `664`、Web サーバーグループが所有者。
