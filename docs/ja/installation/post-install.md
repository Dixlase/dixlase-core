# インストール後チェックリスト
インストールウィザードが完了したら、このチェックリストに従ってインストールの検証とサイトのセキュリティ強化を行います。

## 検証

### 1. 管理者ログイン

インストール時に作成した認証情報で管理パネルにログインします：

```
https://your-domain.com/{admin-url}
```

ダッシュボードがエラーなく表示されることを確認してください。

### 2. メール配信

インストール中にメールテストをスキップした場合は、ここでメール配信を検証します：

1. **設定 > 基本 > メール**に移動
2. 必要に応じて SMTP 設定を更新
3. テストメール機能を使用して配信を確認

メールはパスワードリセット、二要素認証コード、セキュリティ通知に不可欠です。

### 3. ストレージシンボリックリンク

公開ストレージリンクが存在することを確認します：

```bash
php artisan storage:link
```

アップロードされたメディアファイルの配信に必要です。

## セキュリティ強化

Dixlase には包括的なセキュリティ機能が含まれています。インストール後にこれらを確認・設定してください。

### 認証

| 機能 | 場所 | 説明 |
|------|------|------|
| 二要素認証 | 設定 > セキュリティ > 2FA | 管理者アカウントに TOTP またはメールベースの 2FA を有効化 |
| パスワードポリシー | 設定 > セキュリティ > パスワード | 最小長、複雑性、有効期限ルール |
| ログイン試行制限 | 設定 > セキュリティ > ログイン試行 | ログイン失敗後のロックアウト |
| CAPTCHA | 設定 > セキュリティ > CAPTCHA | ログインや登録フォームに CAPTCHA を追加 |

### アクセス制御

| 機能 | 場所 | 説明 |
|------|------|------|
| IP ホワイトリスト/ブラックリスト | 設定 > セキュリティ > IP ホワイトリスト | IP アドレスによる管理アクセス制限 |
| セッション設定 | 設定 > セキュリティ > セッション | セッション有効期間、暗号化、ドライバー |
| 管理URL | 設定 > 基本 > 管理 | 管理パネルの URL パスを変更 |

### コンテンツセキュリティ

| 機能 | 場所 | 説明 |
|------|------|------|
| CSP（コンテンツセキュリティポリシー） | 設定 > セキュリティ > CSP | HTTP セキュリティヘッダーを設定 |
| ファイル整合性監視 | 設定 > セキュリティ > ファイル整合性 | 不正なファイル変更を検出 |
| SSL / HTTPS 強制 | 設定 > セキュリティ > 環境 | HTTPS 接続を強制 |

## 推奨される即時アクション

1. すべての管理者アカウントで**2FA を有効化** — これが最も効果的なセキュリティ対策です
2. デフォルトの `admin` から**管理URLを変更**してカスタムパスに設定
3. 管理アクセスを特定のネットワークに限定すべき場合は**IP 制限を設定**
4. **CSP 設定を確認**し、準備ができたら厳格モードを有効化
5. 機密環境では**セッション暗号化を設定**

## パフォーマンス

### キャッシュ設定

本番環境向け：

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

### キューワーカー

キューワーカーをまだ設定していない場合は、[手動インストール](manual.md#8-インストール後の設定)ガイドの systemd 設定を参照してください。
