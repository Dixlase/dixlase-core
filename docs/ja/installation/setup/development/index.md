# 開発環境

Dixlaseのローカル開発環境を構築します。ワークフローに合った方法を選択してください。

## 推奨

- [Docker](docker.md) — 全サービス（PHP、データベース、Webサーバー、メール、キャッシュ）がコンテナで事前設定済み。Mac、Windows、Linuxで動作。

## その他の方法

- [Laravel Herd](laravel-herd.md) — Mac/Windows向けワンクリックPHP + Nginxセットアップ
- [XAMPP / MAMP](xampp-mamp.md) — クラシックなGUIベースのローカルサーバーパッケージ
- [Valet](valet.md) — Mac向け軽量バックグラウンドサーバー
- [手動セットアップ](manual.md) — PHP、Composer、データベースを個別にインストール
