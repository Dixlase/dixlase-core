# 本番環境

このセクションでは、Dixlase を本番環境で運用するためのデプロイオプションを紹介します。インフラと運用要件に最適なアプローチを選択してください。

## デプロイオプション

- [VPS / クラウドサーバー](vps-cloud.md) — VPS やクラウドインスタンスに Nginx + PHP-FPM + MariaDB/MySQL でデプロイ。
- [共有レンタルサーバー](shared-hosting.md) — 日本で一般的な共有レンタルサーバーへのデプロイ。
- [Docker 本番環境](docker-production.md) — コンテナ化された Dixlase を本番環境で運用。
- [PaaS デプロイ](paas.md) — Laravel Forge や Ploi などのマネージドプラットフォームを利用。
