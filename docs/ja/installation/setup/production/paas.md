# PaaS デプロイ

Laravel Forge や Ploi などのマネージドプラットフォームに Dixlase をデプロイします。これらのサービスはサーバーのプロビジョニング、デプロイ、SSL 証明書、監視を自動化し、アプリケーションに集中できます。

## 前提条件

- PaaS プロバイダーのアカウント（例: Laravel Forge、Ploi、Laravel Cloud）
- 連携済みのクラウドサーバープロバイダー（例: DigitalOcean、AWS、Hetzner）
- ドメイン名（推奨）
