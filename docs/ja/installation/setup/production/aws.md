# AWS（Amazon Web Services）

AWS EC2 と RDS で Dixlase をデプロイします。

## 前提条件

- AWS アカウント
- Ubuntu 22.04+ または Amazon Linux 2023 を実行する EC2 インスタンス
- RDS インスタンス（MySQL 8.0+ または MariaDB 10.6+）
- EC2 インスタンスへの SSH アクセス
- ドメイン名（推奨）
