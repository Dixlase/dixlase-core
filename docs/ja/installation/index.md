# インストールガイド
このガイドでは、Dixlase CMS をサーバーにインストールする手順を説明します。お使いの環境に合った方法をお選びください。

## 前提条件

インストール前に、[システム要件](requirements.md)を満たしていることを確認してください。

## セットアップ

環境に合ったセットアップ方法を選択してください。

- [セットアップガイド](setup/index.md) - Docker を含む利用可能な方法

## インストールウィザード

サーバー環境のセットアップ後、Web ベースのインストーラが初期設定をガイドします：

- [インストールウィザード](wizard.md) - データベース、メール、管理者アカウント、サイト設定
