# インストールガイド

> **[English version](../../installation/index.md)**

このガイドでは、Dixlase CMS をサーバーにインストールする手順を説明します。お使いの環境に合った方法をお選びください。

## 前提条件

インストール前に、[システム要件](requirements.md)を満たしていることを確認してください。

## インストール方法

### Docker（開発環境推奨）

ローカル開発環境を最も素早く構築できる方法です。すべてのサービスが事前設定済みです。

- [Docker セットアップ](docker.md) - クローン、設定、Docker Compose で起動

### 手動インストール（本番環境）

本番サーバーや Docker が利用できない環境向けです。

- [手動インストール](manual.md) - Nginx または Apache でのステップバイステップのサーバー構築

## インストールウィザード

サーバー環境のセットアップ後、Web ベースのインストーラが初期設定をガイドします：

- [インストールウィザード](wizard.md) - データベース、メール、管理者アカウント、サイト設定

## インストール後

- [インストール後チェックリスト](post-install.md) - インストールの検証とセキュリティ強化
