# セーフモードガイド
## 概要

Dixlaseは、クラッシュリカバリーのための**マルチレベルセーフモードシステム**を提供しています。CSP設定の誤り、プラグインの不具合、テーマの破損などで通常のアクセスができなくなった場合に、SSHやCLIなしで管理者が制御を回復できます。

すべてのセーフモードは**セッションベース**（DB書き込みなし）です。有効にできるのは**スーパー管理者**だけで、それ以外のユーザーの `?safe=` は無視されます。

## セーフモードレベル

| モード | URLパラメータ | 効果 | スコープ |
|--------|-------------|------|---------|
| **CSP** | `?safe=csp` | CSPヘッダーを無効化 | 全ページ（セッション） |
| **プラグイン** | `?safe=plugins` | プラグインのコントローラーが処理するルートを止め、管理画面のプラグインアセットを読み込まない。プラグイン自体は読み込まれる | そのセッション |
| **テーマ** | `?safe=theme` | テーマを無効化し、最小限のフォールバックレイアウトで表示 | フロントのみ（セッション） |

### 後方互換性

`?safe=1` は後方互換性のため `?safe=csp` として処理されます。

### 複数モードの同時指定

カンマ区切りで複数モードを同時に有効化できます：

```
https://your-site.com/admin?safe=csp,plugins
```

---

## 有効化の方法

### 方法1: URLパラメータ（推奨）

管理者としてログインした状態で、任意のページURLに `?safe=<mode>` を追加します：

```
https://your-site.com/admin?safe=csp
https://your-site.com/admin?safe=plugins
https://your-site.com/?safe=theme
https://your-site.com/admin?safe=csp,plugins
```

### 方法2: CSP自動有効化

CSP設定を保存後、確認モーダルがタイムアウト（10秒）すると、自動的にロールバックされCSPセーフモードが有効になります。

---

## セーフモードバナー

セーフモードが有効な場合、管理画面の上部にカラーバナーが表示されます：

| モード | バナー色 | メッセージ |
|--------|---------|-----------|
| CSP | 赤 | 「CSPセーフモードが有効です」 |
| プラグイン | オレンジ | 「プラグインセーフモードが有効です」 |
| テーマ | 紫 | 「テーマセーフモードが有効です」 |

各バナーには以下が含まれます：
- 関連する設定ページへのリンク
- そのモードを解除する「解除」ボタン
- 複数モードが有効な場合の「すべて解除」ボタン

---

## 解除方法

### 管理画面から解除

1. セーフモードバナーの「解除」ボタンをクリック
2. または、関連する設定ページに移動して設定を修正

### コマンドラインから解除（Artisan）

```bash
# CSPセーフモードを解除
php artisan csp:disable-safe-mode
```

## モード詳細

### CSPセーフモード (`?safe=csp`)

**使用場面:** CSP設定の誤りにより、JavaScriptやスタイルがブロックされ、管理画面が正常に使用できない場合。

**動作:**
- `CspBuilder` がCSPヘッダーの出力を完全にスキップ
- すべてのスクリプトとスタイルが制限なく読み込まれる
- 赤いバナーで管理者に警告

**セキュリティへの影響:** XSS攻撃の対象面が増加します。CSP設定を修正したら速やかに解除してください。

**関連設定:** 管理画面 > 全体設定 > セキュリティ > CSP設定

### プラグインセーフモード (`?safe=plugins`)

**使用場面:** プラグインの不具合により、Fatal Error、管理画面の表示崩れなどが発生し、通常の管理画面アクセスができない場合。

**動作:**
- そのセッションでは、プラグインのコントローラー（`Plugins\` 名前空間のクラス）が処理するルートへのリクエストが、管理画面のダッシュボードにリダイレクトされる
- 管理画面でプラグインアセットが読み込まれない（`load_active_assets()` がプラグインアセットをスキップ）
- コアの管理画面ページは使える

**動作しないこと:**
- プラグインを無効にはしない。有効なプラグインはリクエストのたびに読み込まれ、ServiceProvider の登録とブートも行われるため、プラグインのコードは動き続ける（イベントリスナー、ミドルウェア、ビューコンポーザー、スケジュールタスクなど）
- プラグインのコントローラー以外が処理するルート（プラグインが登録したクロージャーのルートなど）は止めない
- 他のセッションや他の管理者には影響しない

プラグインの ServiceProvider の読み込み中に起きるエラーは、セーフモードでは避けられない。

**関連設定:** 管理画面 > 全体設定 > プラグイン

### テーマセーフモード (`?safe=theme`)

**使用場面:** テーマの破損により、フロントエンドのページが正しくレンダリングされない場合。

**動作:**
- `themes::` ビュー名前空間を `resources/views/safe-theme/` にオーバーライド
- 最小限のHTML5レイアウトでページを表示（コアのTailwind CSS + Alpine.jsのみ）
- テーマアセットが読み込まれない（`load_front_assets()` がテーマアセットをスキップ）

**重要:** テーマセーフモードはフロントエンドページのみに影響します。管理画面は影響を受けません。

**関連設定:** 管理画面 > 全体設定 > テーマ

## アーキテクチャ

### セッションキー

各モードはセッションに状態を保存します：

| モード | セッションキー |
|--------|---------------|
| CSP | `safe_mode_csp` |
| プラグイン | `safe_mode_plugins` |
| テーマ | `safe_mode_theme` |

### 主要コンポーネント

| コンポーネント | ファイル | 役割 |
|---------------|---------|------|
| `SafeMode` (Enum) | `app/Enums/SafeMode.php` | モード定義とヘルパーメソッド |
| `SafeModeService` | `app/Services/SafeModeService.php` | 有効化、無効化、状態クエリ |
| `SafeMode` (Middleware) | `app/Http/Middleware/SafeMode.php` | URLパラメータ検出、テーマ名前空間オーバーライド |
| `BlockPluginRoutes` | `app/Http/Middleware/BlockPluginRoutes.php` | プラグインルートブロック |
| `SafeModeBanner` | `app/View/Components/Security/SafeModeBanner.php` | バナーレンダリング |
| `SafeModeController` | `app/Http/Controllers/Admin/SafeModeController.php` | 解除エンドポイント |

### リクエストフロー

1. **SafeMode ミドルウェア** が `?safe=` パラメータを検出し、セッションにモードを保存
2. **BlockPluginRoutes ミドルウェア** がルートコントローラーが `Plugins\` 名前空間かをチェックし、プラグインセーフモード有効時はリダイレクト
3. **CspBuilder** が `safe_mode_csp` セッションをチェックし、有効時はCSPヘッダーをスキップ
4. **AssetHelper** が `safe_mode_plugins` / `safe_mode_theme` をチェックし、アセットをスキップ
5. **SafeModeBanner コンポーネント** が有効なモードを読み取りバナーをレンダリング

### ログ記録

すべてのセーフモードの有効化・無効化は `admin_activity` チャンネルに記録されます：
- モード名
- ユーザーIDと名前
- IPアドレスとUser-Agent
- タイムスタンプ

---

## 注意事項

- **セーフモードは一時的なリカバリー措置です。** 根本的な問題を解決したら速やかに解除してください。
- **CSPセーフモード** はXSS保護を無効化します。本番環境で有効なまま放置しないでください。
- **プラグインセーフモード** は、プラグインのコントローラーが処理するルートを止め、管理画面のプラグインアセットを読み込まないだけです。プラグインの ServiceProvider は読み込まれてブートするため、プラグインのコードは動きます。
- **テーマセーフモード** はテーマスタイリングなしの最小限レイアウトを提供します。コンテンツは引き続き表示されます。
- セーフモードはセッション単位です。他のログイン中の管理者には影響しません。
- ログアウトするとセッションが終了し、すべてのセーフモードが解除されます。
