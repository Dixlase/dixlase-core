# かんたんモードと詳細モード

Dixlaseの管理画面には2つのモードがあります。モードの切り替えは **全体設定 > 基本設定 > モード設定** から行えます。

## かんたんモード（デフォルト）

日常的な操作向けに設計されています。セキュリティ設定は安全なデフォルト値で自動設定され、リスクの高い設定は事故防止のため非表示になります。

## 詳細モード

すべての機能と設定にアクセスできます。完全な制御が必要な経験豊富な管理者向けです。

## モードによる違い

### 常に利用可能（両モード共通）

| 機能 | 備考 |
|------|------|
| ダッシュボード | 全機能利用可 |
| フロントページ管理 | 作成・編集・リセット |
| メディアのアップロード・閲覧 | ファイルのアップロードと管理 |
| プロフィール設定 | アカウント情報、パスワード、外観、2FA |
| 基本設定（サイト情報） | サイト名、説明、OGP |
| メンテナンスモード | メンテナンスの有効化/無効化 |
| モード設定 | かんたんモード/詳細モードの切り替え |
| テーマ管理 | テーマのインストール・切替・削除 |
| プラグイン管理 | プラグインのインストール・有効化・無効化 |
| キャッシュ管理 | アプリケーションキャッシュのクリア |

### かんたんモードで一部制限あり（Partial）

基本操作は可能ですが、一部の詳細パラメータは安全なデフォルト値で自動設定されます。

| 機能 | できること | 自動設定されること |
|------|-----------|-------------------|
| メディア設定 | 許可するファイルタイプの選択、サイズ制限 | MIME検証・SVGサニタイズ・ZIPセキュリティチェックは常にON |
| メール設定 | 管理者メールアドレスの設定 | SMTPサーバー詳細（詳細モードへ誘導） |
| ログインセキュリティ | ログイン通知の設定 | 試行制限回数、ロックアウト時間、ロックアウト通知 |
| 二段階認証 | 2FA・パスキーの有効化/無効化 | デバイス制限数、有効期限、回復コード設定 |
| CAPTCHA | プロバイダー選択、APIキー入力、フォーム別トグル | 新規プラグインのフォームはCAPTCHAが自動有効化 |

### かんたんモードで非表示（Hidden）

これらの設定は非表示で自動設定されます。変更するには詳細モードに切り替えてください。

| 設定 | 自動設定値 |
|------|-----------|
| パスワードポリシー | 最小8文字、大文字+数字+記号必須、漏洩チェックON |
| セッション有効時間 | 120分 |
| CSP（コンテンツセキュリティポリシー） | ON、標準モード、警告のみ |
| エラー通知 | ON、Critical以上 |
| 環境設定 | 本番環境、デバッグOFF |
| IPアクセス制御 | 無効 |
| 管理画面URL | 読み取り専用（詳細モードへ誘導） |
| メンバー権限設定 | デフォルトテンプレートを維持 |
| データベースクリーンアップ | 詳細モードでのみ手動操作可 |
| API管理 | 無効 |

### かんたんモードで閲覧のみ（ReadOnly）

設定内容を確認できますが、変更はできません。

| 設定 | 表示内容 |
|------|---------|
| セキュリティ概要 | 全セキュリティ設定のサマリー |
| 拡張セキュリティ | 現在のセキュリティプリセット |
| ログ管理 | 監査ログ・ファイルログの閲覧（エクスポート不可） |
| システム情報 | サーバー環境、PHP、データベース情報 |

## モード切り替え時の動作

- **かんたん → 詳細**: すべての機能が即座に解放されます。自動設定値は明示的に変更するまでそのまま残ります。
- **詳細 → かんたん**: 確認ダイアログが表示されます。非表示の設定は安全なデフォルト値で上書きされます。
