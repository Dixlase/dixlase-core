# フロントページ管理

サイトのフロントページコンテンツを管理します。言語やエディタータイプを選択して、フロントページの作成・編集・リセットができます。

## 概要

フロントページマスターでは、現在のフロントページコンテンツが表示されます。ここから以下の操作が可能です：

- **作成** — フロントページが存在しない場合に新規作成
- **編集** — 既存のフロントページコンテンツを編集
- **エディタータイプの選択** — ワークフローに合ったエディターを選択
- **言語バージョンの管理** — 言語ごとのフロントページコンテンツを作成・編集

## フロントページ設定

設定ページからフロントページの動作を構成できます：

| 設定 | 説明 |
|------|------|
| エディタータイプ | フロントページ編集に使用するデフォルトエディターを選択 |
| 言語 | フロントページコンテンツの言語を設定 |

## 備考

- フロントページはサイトのルートURLに表示されるコンテンツです。
- フロントページ編集では、システム設定で利用可能なエディタータイプと同じものが使用できます。
