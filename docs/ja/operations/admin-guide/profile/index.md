# プロフィール設定

アカウント情報、セキュリティ設定、外観設定、通知設定、二段階認証などを管理します。

## セクション

### 基本情報

表示名、メールアドレス、その他のアカウント情報を編集します。

### パスワード

ログインパスワードを変更します。確認のため現在のパスワードの入力が必要です。

### 外観

管理パネルの外観をカスタマイズします：

- **テーマ** — ライトモードとダークモードを切り替え
- **言語** — 管理パネルの表示言語を変更

### 通知

通知の受信方法とタイミングを設定します：

- ログイン通知（アカウントにアクセスがあった場合のメール通知）
- システム通知

### 二段階認証

アカウントにセキュリティの追加レイヤーを設定します：

- **TOTP** — 認証アプリを使用（例: Google Authenticator、Authy）
- **WebAuthn** — ハードウェアセキュリティキーまたは生体認証を使用

有効にすると、ログイン時にパスワード入力後に二段階目の認証が求められます。
