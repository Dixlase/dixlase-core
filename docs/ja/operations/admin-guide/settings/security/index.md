# セキュリティ設定

セキュリティ設定の概要と各機能の状態を確認できます。パスワードポリシー、ログイン保護、セッション、二段階認証、CAPTCHA、IPアクセス制御、CSPなどの設定を行います。

## 概要ページ

セキュリティ設定の概要ページでは、各セキュリティ機能の状態（有効・無効・要対応）が表示されます。機能をクリックして設定を行います。

## 機能

| 機能 | 説明 |
|------|------|
| パスワードポリシー | 最小文字数、複雑さの要件、辞書攻撃対策 |
| ログイン保護 | ログイン失敗後のアカウントロック、ロック期間、通知設定 |
| セッション管理 | セッション有効期間、同時セッション制御、セッションセキュリティ |
| 二段階認証 | メンバーへのTOTPおよびWebAuthnの強制または推奨 |
| CAPTCHA | ログインやその他のフォームでCAPTCHAを有効にし、自動攻撃を防止 |
| IPアクセス制御 | 管理パネルへのアクセスをIPアドレスで許可リスト・拒否リストで制御 |
| Content Security Policy (CSP) | XSSやインジェクション攻撃を防止するCSPヘッダーの設定 |
| セキュリティ通知 | ログインイベントや不審なアクティビティのメール通知 |
| ファイル整合性 | コアファイルの不正な変更を監視 |
| 環境セキュリティ | サーバー環境設定のセキュリティベストプラクティスの確認 |
