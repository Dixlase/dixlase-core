# テーマ管理

インストール済みテーマの管理、新しいテーマの追加、アクティブテーマの切り替えを行います。

## テーママスター

インストール済みおよび利用可能なテーマを一覧表示します：

- **インストール済みテーマ** — `themes/` ディレクトリに配置されているテーマ。有効化、無効化、削除が可能です。
- **新しいテーマの追加** — テーマのZIPファイルをアップロードするか、`themes/` ディレクトリに配置してインストールします。

## テーマの切り替え

サイトの外観を変更するには、使用したいテーマの**有効化**をクリックします。一度にアクティブにできるテーマは1つだけです。テーマを切り替えてもコンテンツには影響しません。

## テーマ情報

各テーマカードには以下の情報が表示されます：

| 項目 | 説明 |
|------|------|
| 名前 | テーマの表示名 |
| バージョン | 現在のバージョン番号 |
| 作者 | テーマの開発者 |
| ライセンス | テーマの配布ライセンス |
| ステータス | 有効、インストール済み、または利用可能 |

## セキュリティ監査

新しいテーマを有効化する前に、Dixlaseはセキュリティ監査を実行して潜在的な問題をチェックします。有効化前に監査結果を確認してください。
