# 基本設定

基本設定の概要と各機能の状態を確認できます。サイト情報、管理画面、メール、メンテナンスモード、表示モードの設定を行います。

## 概要ページ

基本設定の概要ページでは、各設定カテゴリの現在の状態が表示されます。カテゴリをクリックして設定を行います。

## カテゴリ

| カテゴリ | 説明 |
|---------|------|
| サイト情報 | サイト名、URL、説明文など、サイトの基本情報 |
| 管理画面 | 管理画面のURLパス、デフォルト言語、管理パネルの動作設定 |
| メール | SMTPサーバー設定とメール送信設定 |
| メンテナンスモード | サイト作業中に訪問者へメンテナンスページを表示する機能の有効化 |
| 表示モード | 管理パネルのかんたんモードと詳細モードの切り替え |
| エディター | デフォルトのコンテンツエディタータイプの設定 |
