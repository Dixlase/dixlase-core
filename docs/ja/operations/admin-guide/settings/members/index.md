# メンバー管理

登録されているメンバーの一覧表示、検索、編集、削除を行います。メンバーの権限、ロール、アクセス制御の設定ができます。

## メンバーマスター

すべての登録メンバーを一元管理します：

- **一覧表示** — ロール、ステータス、最終ログインとともに全メンバーを表示
- **検索** — 名前、メールアドレス、ロールでメンバーを検索
- **作成** — 新しいメンバーを追加してロールを割り当て
- **編集** — メンバー情報の更新、ロール変更、パスワードリセット
- **削除** — システムからメンバーを削除

## ロール権限

各ロールが管理パネル内でアクセス・操作できる範囲を設定します：

- **スーパー管理者** — すべての機能にフルアクセス（変更不可）
- **カスタムロール** — 管理パネルの各セクションに対してきめ細かい権限を定義

権限はカテゴリ別（コンテンツ、メディア、設定、メンバー、システムなど）に整理されており、ロールごとに許可・拒否を設定できます。

プラグイン固有の権限もここで管理されます。プラグインは独自の権限グループを登録でき、コア権限と並んで表示されます。
