# システム

キャッシュ管理、データベースクリーンアップ、ログ管理、API設定、システム情報など、各種システム管理機能にアクセスできます。

## 機能

| 機能 | 説明 |
|------|------|
| キャッシュ管理 | アプリケーションキャッシュ、ルートキャッシュ、ビューキャッシュ、設定キャッシュのクリア。設定変更やアップデート後に有用です。 |
| データベース管理 | 古いデータベースレコード（セッション、ログ、一時データ）をクリーンアップしてパフォーマンスを維持します。自動クリーンアップルールの設定も可能です。 |
| システム情報 | サーバー環境の詳細を表示 — PHPバージョンと拡張、データベースバージョン、ディスク使用量、Laravelバージョン、その他の診断情報。 |
| API管理 | REST API設定の構成、APIキーの管理、APIリクエストの署名検証の設定。 |
| ログ管理 | システムのアクティビティログの表示・検索・エクスポート。セキュリティ監査やトラブルシューティングのための管理者アクションの追跡。 |
