# プラグイン管理

インストール済みプラグインの管理、新しいプラグインの追加、プラグインの有効化・無効化を行います。

## プラグインマスター

インストール済みおよび利用可能なプラグインを一覧表示します：

- **インストール済みプラグイン** — `plugins/` ディレクトリに配置されているプラグイン。有効化、無効化、削除が可能です。
- **新しいプラグインの追加** — プラグインのZIPファイルをアップロードするか、`plugins/` ディレクトリに配置してインストールします。

## プラグインの有効化と無効化

- **有効化** — プラグインをアクティブにし、マイグレーションを実行して、ルートとサービスを登録します。
- **無効化** — データを削除せずにプラグインを非アクティブにします。いつでも再有効化できます。

## プラグイン情報

各プラグインカードには以下の情報が表示されます：

| 項目 | 説明 |
|------|------|
| 名前 | プラグインの表示名 |
| バージョン | 現在のバージョン番号 |
| 作者 | プラグインの開発者 |
| ライセンス | プラグインの配布ライセンス |
| ヘルススコア | 自動スキャンに基づくセキュリティと品質のスコア |
| ステータス | 有効、無効、または利用可能 |

## 権限とセキュリティ

新しいプラグインを有効化する前に、宣言された権限（データベース、ストレージ、設定、メールなどのシステムリソースへのアクセス）を確認できます。Dixlaseは潜在的な問題をチェックするセキュリティ監査も実行します。

## ヘルススコアリング

Dixlaseは以下の基準で各プラグインを自動的にスコアリングします：

- 適切な権限宣言
- 正しいファイル構造と命名規則
- 宣言と実際の機能の一貫性
