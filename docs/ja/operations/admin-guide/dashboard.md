# ダッシュボード

ダッシュボードは管理パネルにログインした後に最初に表示されるページです。サイトの状態を一目で確認できます。

## ウィジェット

| ウィジェット | 説明 |
|------------|------|
| コンテンツウィジェット | プラグインが管理するサイトコンテンツの概要 |
| システム情報 | サーバー環境の概要 — PHPバージョン、データベース、キャッシュドライバー、ストレージ使用量 |
| セキュリティ概要 | 主要なセキュリティ機能の状態 — 2FA、CSP、CAPTCHA、ログイン保護 |
| 最近のアクティビティ | 監査ログの最新エントリ — 誰がいつ何をしたか |
| メンバー概要 | メンバー総数とロール別の内訳 |
| 拡張機能概要 | インストール済みプラグインとテーマの状態 |
| プラグイン通知 | インストール済みプラグインからのアラートとメッセージ |

## 備考

- ウィジェットはロール権限に基づいて表示されます。権限が付与されていない場合、一部のウィジェットが表示されないことがあります。
- ダッシュボードは読み取り専用です。ステータス情報を表示しますが、設定の変更はできません。各ウィジェット内のリンクから該当する設定ページに移動してください。
