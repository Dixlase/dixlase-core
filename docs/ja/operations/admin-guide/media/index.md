# メディア管理

画像、動画、ドキュメントなどのメディアファイルを管理します。ファイルのアップロード、許可するファイルタイプやサイズ制限の設定ができます。

## メディアマスター

アップロード済みのメディアファイルを一覧表示します。以下の操作が可能です：

- グリッドまたはリスト形式でファイルを表示
- 画像、動画、ドキュメントのプレビュー
- ファイルタイプによる検索・フィルタリング
- 不要なファイルの削除

## メディアアップロード

メディアライブラリに新しいファイルをアップロードします：

- ドラッグ＆ドロップまたはクリックしてファイルを選択
- 複数ファイルの同時アップロード
- メディア設定に基づいて、許可されたファイルタイプと最大ファイルサイズが適用されます

## メディア設定

サイトのメディア処理を設定します：

| 設定 | 説明 |
|------|------|
| 許可するファイルタイプ | アップロード可能なファイル拡張子を指定（例: jpg, png, pdf, mp4） |
| 最大ファイルサイズ | 1ファイルあたりのアップロードサイズの上限を設定 |

## コマンドラインからファイルを取り込む

`dls:media:import` は、アップロード画面を使わずにローカルのファイルをメディアライブラリに登録する。たとえば、スクリプトやアシスタントが記事用に用意した画像を取り込むときに使う。

```bash
php artisan dls:media:import cover.png figure-1.jpg --as=editor@example.com
php artisan dls:media:import cover.png --as=3 --json
```

- `--as`（必須）で、アップロードを記録するメンバーを ID かメールアドレスで指定する。そのメンバーは有効で、メディアのアップロード権限を持っている必要がある。監査ログには、各アップロードがそのメンバーで記録される
- 各ファイルは管理画面からのアップロードとまったく同じに検査される。メディア設定の許可するファイル形式と最大サイズ、セキュリティの検査、SVG の無害化
- 既存のメディアと内容が同じファイルは保存し直さず、「ライブラリに登録済み」として既存のものを返す
- `--json` を付けると、ファイルごとにメディアの `id`・`name`・`type`・`width`・`height`、エディタが挿入するルート相対の `path`、絶対 URL の `url` を出す。失敗したファイルは `error` を出す
- 1 件でも失敗すると終了コードは 0 以外になる。ほかのファイルは取り込まれる

## 備考

- アップロードされたファイルはサイトのストレージディレクトリに保存されます。
- ファイルタイプとサイズの制限により、悪意のあるアップロードからサイトを保護します。
