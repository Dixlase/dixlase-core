# Dixlaseとは

Dixlaseは、Laravelで構築されたオープンソースのコンテンツ管理システムです。セキュリティ、シンプルさ、プラグインによる拡張性を重視した、モダンで拡張可能なWebサイト構築・管理プラットフォームを提供します。

## 主な特徴

- **2つの管理モード** — 安全なデフォルト値で日常操作に集中できるかんたんモードと、全機能にアクセスできる詳細モード
- **プラグインシステム** — セキュリティスキャンとヘルススコアリングを備えたプラグインで機能を拡張
- **テーマシステム** — インストール可能なテーマでサイトの外観をカスタマイズ
- **日本語・英語に対応** — 管理画面とメッセージを日本語・英語で表示
- **セキュリティファースト** — CSPヘッダー、二段階認証（TOTPおよびWebAuthn）、監査ログ、CAPTCHA、ログイン通知など
- **モダンな技術スタック** — Laravel 13、Alpine.js 3、Tailwind CSS 4

## アーキテクチャ

Dixlaseはモジュラーアーキテクチャを採用しており、コア機能を最小限に保ち、プラグインとテーマで機能を追加する設計です。

### コア

コアは基盤となる機能を提供します。認証、メンバー管理、ロールベースアクセス制御、メディア管理、フロントページ編集、設定、管理パネルなどです。プラグイン・テーマのローディング、セキュリティ基盤、システムメンテナンスツールも含まれます。

### プラグイン

プラグインは `plugins/` ディレクトリに配置される自己完結型のパッケージです。各プラグインは独自のルート、ビュー、マイグレーション、設定、翻訳を宣言します。プラグインは定義されたコントラクトとAPIを通じてのみコアと連携するため、他のシステムに影響を与えることなくインストール・削除が可能です。

### テーマ

テーマはサイトの見た目を制御します。`themes/` ディレクトリに配置され、コンテンツを変更することなく管理パネルから切り替えができます。

## Dixlaseの対象ユーザー

- **サイトオーナー** — 使いやすさを犠牲にせず、デフォルトでセキュアなCMSを求める方
- **開発者** — クリーンなプラグインアーキテクチャを持つモダンなLaravel基盤で開発したい方
- **組織・企業** — 監査ログ、アクセス制御、コンプライアンス対応のセキュリティ機能が必要な方
