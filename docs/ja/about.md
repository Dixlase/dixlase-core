# Dixlaseとは

Dixlaseは、Laravelで構築されたオープンソースのコンテンツ管理システムです。セキュリティ、シンプルさ、プラグインによる拡張性を重視した、モダンで拡張可能なWebサイト構築・管理プラットフォームを提供します。

## 主な特徴

- **2つの管理モード** — 安全なデフォルト値で日常操作に集中できるかんたんモードと、全機能にアクセスできる詳細モード
- **プラグインシステム** — セキュリティスキャンとヘルススコアリングを備えたプラグインで機能を拡張
- **テーマシステム** — インストール可能なテーマでサイトの外観をカスタマイズ
- **多言語対応** — 複数言語のサポートを標準搭載
- **セキュリティファースト** — CSPヘッダー、二段階認証、監査ログ、CAPTCHA、その他多数
- **モダンな技術スタック** — Laravel 12、Livewire 4、Alpine.js 3、Tailwind CSS 3
