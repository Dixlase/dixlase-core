## プラグイン・テーマ例外条項

AGPL v3 第7条に基づく特別例外として、**Plugin API のみを通じて**Dixlase CMS と連携するプラグインおよびテーマは、Dixlase CMS の派生物とは**みなされません**。プロプライエタリライセンスを含む、任意のライセンスで配布することができます。

この例外は、以下の条件が**すべて**満たされる場合にのみ適用されます:

1. プラグイン/テーマが、`PLUGIN-API.md` に定義されたインターフェースのみを通じて Dixlase CMS と通信すること
2. プラグイン/テーマが、コアのソースファイルを変更・置換・モンキーパッチしないこと
3. プラグイン/テーマが、コアサービスの内部実装を迂回・複製しないこと
4. プラグイン/テーマが、標準の読み込み機構（`PluginLoaderTrait` / `ThemeLoaderTrait`）を通じて読み込まれ、`plugins/` または `themes/` ディレクトリに配置されていること

いずれかの条件が満たされない場合、そのプラグインまたはテーマは派生物とみなされ、AGPL-3.0 の全条項が適用されます。

詳細は、ソースコードに同梱されている `LICENSE` ファイル（「Dixlase プラグイン・テーマ例外条項」セクション）および `PLUGIN-API.md` を参照してください。

## サードパーティライセンス

各プラグインやテーマは、`plugin.json` または `theme.json` ファイルで独自のライセンスを指定する場合があります。インストールする各拡張機能の個別ライセンスを確認してください。
