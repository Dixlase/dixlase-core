# 初心者ガイド
このガイドでは、Dixlase 管理パネルのレイアウト、主要セクション、コア機能を紹介します。[インストールガイド](../installation/index.md)を完了した後、このガイドを使ってサイト管理に慣れてください。

## 管理パネルへのアクセス

ブラウザを開いて以下にアクセスします：

```
https://your-domain.com/{admin-url}
```

`{admin-url}` はインストール時に設定したパスです（デフォルト: `admin`）。作成したスーパー管理者の認証情報でログインしてください。

## ダッシュボード

ダッシュボードはログイン後のランディングページです。サイトのステータスとアクティビティの概要を一目で確認できます。

## 主要セクション

管理パネルは以下のセクションに分かれており、サイドバーナビゲーションからアクセスできます。

### フロント（コンテンツ管理）

サイトの公開ページを管理します。

| ページ | 説明 |
|--------|------|
| 一覧 | すべてのページを表示・管理 |
| 編集 | 個別ページの作成・編集 |
| 設定 | フロントエンド表示オプションの設定 |

### メディア

アップロードされた画像、ドキュメント、その他のファイルを管理します。

| ページ | 説明 |
|--------|------|
| 一覧 | メディアライブラリを閲覧 |
| アップロード | 新しいファイルをアップロード |
| 設定 | メディアストレージと処理オプションの設定 |

### メンバー

管理ユーザーとそのアクセスレベルを管理します。

| ページ | 説明 |
|--------|------|
| 一覧 | 全メンバーの一覧表示 |
| 作成 / 編集 | 新しいメンバーの追加または既存メンバーの編集 |
| ロール | ロールベースのアクセス権限の設定 |

### メンバーロール

Dixlase はロール階層を使用してアクセスを制御します。優先度の高いロールは、低いロールのユーザーを管理できます。

| ロール | 優先度 | 説明 |
|--------|--------|------|
| スーパー管理者 | 10 | 全システムアクセス、すべての設定とユーザーを管理可能 |
| 管理者 | 9 | ほぼ完全なアクセス、ほとんどの設定を管理可能 |
| 編集者 | 8 | コンテンツの編集・公開が可能 |
| 著者 | 7 | コンテンツの作成が可能、公開は制限付き |
| 寄稿者 | 6 | 下書きの作成が可能、公開は不可 |
| 受付 | 5 | 限定的な運用アクセス |
| ゲスト | 1 | 最小限の読み取り専用アクセス |

メンバーは、自身のロール優先度より低いユーザーのみ管理できます。

### 設定

包括的なサイト設定で、カテゴリごとに分かれています。

#### 基本設定

| ページ | 説明 |
|--------|------|
| サイト | サイト名、言語、タイムゾーン |
| 管理 | 管理パネルの URL と動作 |
| メール | SMTP とメール配信設定 |
| メンテナンス | メンテナンスモードの設定 |
| モード | シンプル/アドバンスド管理モードの切り替え |

#### セキュリティ設定

| ページ | 説明 |
|--------|------|
| パスワード | パスワードポリシールール |
| ログイン試行 | ログイン失敗時のロックアウト閾値 |
| 2FA | 二要素認証の設定 |
| 通知 | セキュリティアラート通知 |
| CAPTCHA | ログイン/フォームの CAPTCHA 設定 |
| セッション | セッションドライバー、有効期間、暗号化 |
| CSP | コンテンツセキュリティポリシーヘッダー |
| 拡張 | セキュリティ拡張の管理 |
| IP ホワイトリスト | IP ベースのアクセス制限 |
| ファイル整合性 | コアファイルの変更監視 |
| 環境 | SSL と環境セキュリティ |

#### テーマ

| ページ | 説明 |
|--------|------|
| 一覧 | インストール済みテーマの表示・切り替え |
| 追加 | 新しいテーマのインストール |

#### プラグイン

| ページ | 説明 |
|--------|------|
| 一覧 | インストール済みプラグインの表示・管理 |
| 追加 | 新しいプラグインのインストール |

#### システム

| ページ | 説明 |
|--------|------|
| キャッシュ | アプリケーションキャッシュのクリアと管理 |
| データベース | データベースの管理とクリーンアップ |
| API | API キーとエンドポイントの設定 |
| ログ | 監査ログとファイルベースのログ |
| 情報 | システム情報と診断 |

### プロフィール

ログイン中のメンバーは自身のプロフィールを管理できます。

| ページ | 説明 |
|--------|------|
| 基本情報 | アカウント名、表示名、メール |
| パスワード | パスワードの変更 |
| 外観 | テーマと UI 設定 |
| 通知 | 通知設定 |
| 2FA | 二要素認証の有効化/無効化 |
| 2FA 管理 | 信頼済みデバイスとリカバリーコードの管理 |

## シンプルモード vs アドバンスドモード

Dixlase では2つの管理モードを提供しています：

| モード | 説明 |
|--------|------|
| **シンプル** | 複雑さを軽減するために詳細設定を非表示にします。日常のコンテンツ管理に最適。 |
| **アドバンスド** | 利用可能なすべての設定と機能を表示します。経験豊富な管理者向け。 |

**設定 > 基本 > モード**でモードを切り替えることができます。

## 新規ユーザー向けのヒント

1. **シンプルモードから始める** — 特定の設定が必要な場合にのみアドバンスドに切り替え
2. **早めに 2FA を有効化** — プロフィール > 2FA でアカウントを保護
3. **メディアライブラリを活用** — ページ作成前に画像をアップロードしておくとすぐに使えます
4. **設定概要を確認** — [設定リファレンス](../settings/index.md)を閲覧して設定可能な項目を把握
5. **管理URL を公開しない** — 管理パネルの URL を一般に共有しないでください
