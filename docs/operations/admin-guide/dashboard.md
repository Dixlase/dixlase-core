# Dashboard

The dashboard is the first page you see after logging in to the admin panel. It provides an at-a-glance overview of your site's status.

## Widgets

| Widget | Description |
|--------|-------------|
| Content Widgets | Quick overview of your site's content managed by plugins |
| System Info | Server environment summary — PHP version, database, cache driver, storage usage |
| Security Overview | Status of key security features — 2FA, CSP, CAPTCHA, login protection |
| Recent Activity | Latest audit log entries showing who did what and when |
| Member Overview | Total members and breakdown by role |
| Extension Overview | Installed plugins and themes with their status |
| Plugin Notifications | Alerts and messages from installed plugins |

## Notes

- Widgets are displayed based on your role permissions. You may not see all widgets if your role does not include the relevant permissions.
- The dashboard is read-only — it displays status information but does not allow configuration changes. Use the links within each widget to navigate to the relevant settings page.
