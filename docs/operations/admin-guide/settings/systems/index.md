# System

Access various system management features including cache management, database cleanup, log management, API settings, and system information.

## Features

| Feature | Description |
|---------|-------------|
| Cache Management | Clear application cache, route cache, view cache, and config cache. Useful after configuration changes or updates. |
| Database Management | Clean up old database records (sessions, logs, temporary data) to maintain performance. Configure automatic cleanup rules. |
| System Info | View server environment details — PHP version and extensions, database version, disk usage, Laravel version, and other diagnostic information. |
| API Management | Configure REST API settings, manage API keys, and set up signature verification for API requests. |
| Log Management | View, search, and export system activity logs. Track administrator actions for security audits and troubleshooting. |
