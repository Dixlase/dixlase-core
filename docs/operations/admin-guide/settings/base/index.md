# Basic Settings

View the overview and status of each basic setting. Configure site information, admin panel, mail, maintenance mode, and display mode.

## Overview Page

The Basic Settings overview page displays the current status of each setting category. Click on any category to configure it.

## Categories

| Category | Description |
|----------|-------------|
| Site Information | Site name, URL, description, and other basic site details |
| Admin Panel | Admin URL path, default language, and admin panel behavior |
| Mail | SMTP server settings and email sending configuration |
| Maintenance Mode | Enable maintenance mode to display a maintenance page to visitors while you work on the site |
| Display Mode | Toggle between Simple Mode and Advanced Mode for the admin panel |
| Editor | Configure the default content editor type |
