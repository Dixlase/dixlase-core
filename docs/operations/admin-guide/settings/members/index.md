# Member Management

View, search, edit, and delete registered members. Configure member permissions, roles, and access control.

## Member Master

Manage all registered members from a single page:

- **View** — Browse all members with their role, status, and last login
- **Search** — Find members by name, email, or role
- **Create** — Add new members and assign roles
- **Edit** — Update member information, change roles, or reset passwords
- **Delete** — Remove members from the system

## Role Permissions

Configure what each role can access and do within the admin panel:

- **Super Admin** — Full access to all features (cannot be modified)
- **Custom Roles** — Define granular permissions for each section of the admin panel

Permissions are organized by category (e.g., content, media, settings, members, system). Each permission can be granted or denied per role.

Plugin-specific permissions are also managed here — plugins can register their own permission groups that appear alongside core permissions.
