# Theme Management

Manage installed themes, add new themes, and switch the active theme.

## Theme Master

View all installed and available themes:

- **Installed themes** — Themes currently in the `themes/` directory. You can activate, deactivate, or remove them.
- **Add new themes** — Upload a theme ZIP file or place it in the `themes/` directory to install.

## Switching Themes

To change your site's appearance, click **Activate** on the theme you want to use. Only one theme can be active at a time. Switching themes does not affect your content.

## Theme Information

Each theme card displays:

| Field | Description |
|-------|-------------|
| Name | Theme display name |
| Version | Current version number |
| Author | Theme developer |
| License | License under which the theme is distributed |
| Status | Active, installed, or available |

## Security Audit

Before activating a new theme, Dixlase performs a security audit to check for potential issues. Review the audit results before proceeding.
