# Security Settings

View the overview and status of each security setting. Configure password policies, login protection, sessions, two-factor authentication, CAPTCHA, IP access control, CSP, and more.

## Overview Page

The Security Settings overview page shows the status of each security feature — enabled, disabled, or requiring attention. Click on any feature to configure it.

## Features

| Feature | Description |
|---------|-------------|
| Password Policy | Minimum length, complexity requirements, and dictionary attack protection |
| Login Protection | Account lockout after failed attempts, lockout duration, and notification settings |
| Session Management | Session lifetime, concurrent session handling, and session security |
| Two-Factor Authentication | Enforce or encourage TOTP and WebAuthn for members |
| CAPTCHA | Enable CAPTCHA on login and other forms to prevent automated attacks |
| IP Access Control | Allowlist or blocklist IP addresses for admin panel access |
| Content Security Policy (CSP) | Configure CSP headers to prevent XSS and other injection attacks |
| Security Notifications | Email alerts for login events and suspicious activity |
| File Integrity | Monitor core files for unauthorized changes |
| Environment Security | Check server environment settings for security best practices |
