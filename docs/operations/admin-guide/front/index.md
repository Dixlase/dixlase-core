# Front Page Management

Manage your site's front page content. Create, edit, or reset the front page with your preferred language and editor type.

## Overview

The Front Page Master displays the current front page content. From here you can:

- **Create** a new front page if one does not exist
- **Edit** the existing front page content
- **Choose editor type** — select the editor that suits your workflow
- **Manage language versions** — create and edit front page content per language

## Front Page Settings

Configure front page behavior from the settings page:

| Setting | Description |
|---------|-------------|
| Editor Type | Choose the default editor for front page editing |
| Language | Set the language for the front page content |

## Notes

- The front page is the content displayed at your site's root URL.
- Front page editing supports the same editor types available in the system settings.
