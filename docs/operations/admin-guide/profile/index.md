# Profile Settings

Manage your account information, security settings, appearance preferences, notification settings, and two-factor authentication.

## Sections

### Basic Information

Edit your display name, email address, and other account details.

### Password

Change your login password. You must enter your current password to confirm the change.

### Appearance

Customize the admin panel appearance:

- **Theme** — Switch between light and dark mode
- **Language** — Change the admin panel interface language

### Notifications

Configure how and when you receive notifications:

- Login notifications (email alerts when your account is accessed)
- System notifications

### Two-Factor Authentication

Set up an additional layer of security for your account:

- **TOTP** — Use an authenticator app (e.g., Google Authenticator, Authy)
- **WebAuthn** — Use a hardware security key or biometric authentication

Once enabled, you will be prompted for a second factor after entering your password during login.
