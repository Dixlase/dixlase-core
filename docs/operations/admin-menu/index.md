# Admin Menu Overview

A reference of all pages available in the Dixlase admin panel and what each one does.

## Dashboard

| Page | Description |
|------|-------------|
| Dashboard | View a summary of your site status. |

## Front Page Management

| Page | Description |
|------|-------------|
| Front Page Master | Manage your site's front page content and templates. |

## Media Management

| Page | Description |
|------|-------------|
| Media Master | Manage uploaded images, videos, documents, and other media files. |
| Media Upload | Upload images, videos, documents, and other files. Allowed file types and size limits apply. |
| Media Settings | Configure allowed file types and maximum file sizes for uploads. |

## Profile Settings

| Page | Description |
|------|-------------|
| Profile Settings | Manage account information, security settings, and appearance preferences. |

## General Settings

### Basic Settings

| Page | Description |
|------|-------------|
| Basic Settings | View an overview of basic settings and the status of each feature. |

### Security Settings

| Page | Description |
|------|-------------|
| Security Settings | View an overview of security settings and the status of each feature. |

### Member Management

| Page | Description |
|------|-------------|
| Member Master | View, search, edit, and delete registered members. |
| Role Permissions | Configure member permissions and access control. |

### Theme Management

| Page | Description |
|------|-------------|
| Theme Master | Manage installed themes, add new themes, and switch active themes. |

### Plugin Management

| Page | Description |
|------|-------------|
| Plugin Master | Manage installed plugins, add new plugins, and enable or disable plugins. |

## System

| Page | Description |
|------|-------------|
| System Overview | Access various system management features. |
| Cache Management | Clear various application caches. |
| Database Management | Clean up old database records to maintain system performance. |
| System Info | View server environment, PHP version, database information, and other system details. |
| API Management | Configure REST API settings, manage API keys, and signature verification. |
| Log Management | View, search, and export system activity history. Track administrator actions for security audits. |
