# Installation Guide

> **[日本語版はこちら](../ja/installation/index.md)**

This guide walks you through installing Dixlase CMS on your server. Choose the method that best fits your environment.

## Prerequisites

Before installing, make sure your environment meets the [System Requirements](requirements.md).

## Installation Methods

### Docker (Recommended for Development)

The fastest way to get a local development environment running. Includes all services pre-configured.

- [Docker Setup](docker.md) - Clone, configure, and launch with Docker Compose

### Manual Installation (Production)

For production servers or environments where Docker is not available.

- [Manual Installation](manual.md) - Step-by-step server setup with Nginx or Apache

## Installation Wizard

After setting up the server environment, the built-in web installer guides you through initial configuration:

- [Installation Wizard](wizard.md) - Database, mail, admin account, and site settings

## After Installation

- [Post-Install Checklist](post-install.md) - Verify your installation and harden security
