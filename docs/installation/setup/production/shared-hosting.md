# Shared Hosting

Deploy Dixlase on shared rental servers. This is a popular hosting option in Japan and suitable for smaller sites that do not require full server control.

## Prerequisites

- A shared hosting plan with PHP 8.2+ and MySQL/MariaDB support
- SSH or FTP access to the server
- Composer (installed locally or available on the server)
