# Development Environment

Set up a local development environment for Dixlase. Choose the method that best suits your workflow.

## Recommended

- [Docker](docker.md) — All services (PHP, database, web server, mail, cache) pre-configured in containers. Works on Mac, Windows, and Linux.

## Alternatives

- [Laravel Herd](laravel-herd.md) — One-click PHP + Nginx setup for Mac and Windows
- [XAMPP / MAMP](xampp-mamp.md) — Classic GUI-based local server packages
- [Valet](valet.md) — Lightweight background server for Mac
- [Manual Setup](manual.md) — Install PHP, Composer, and database individually
